# 🎬 ZTT: LICENCJA NA ZYSK — pakiet produkcyjny teasera

Kompletny pakiet do wyprodukowania 75-sekundowego teasera **Złap Trend Terminal**
w stylu kina szpiegowskiego: AI-wideo (Veo 3 / Kling / Runway) + ElevenLabs
(sklonowany głos właściciela, muzyka, SFX).

| Plik | Zawartość |
|---|---|
| `01-koncepcja.md` | Logline, tytuł, ton, bohater 00ZTT, motyw „lufy ze świec", nota prawna |
| `02-scenariusz.md` | Pełny scenariusz 10 scen z timecode'ami, dialogi, komplet linii VO |
| `03-prompty-wideo.md` | Shot-lista: gotowe prompty Veo 3.1 (EN), warianty Kling/Runway, cut-downy 9:16 |
| `04-voiceover-elevenlabs.md` | Skrypt VO z audio tagami v3, ustawienia głosu-klona, głos femme fatale |
| `05-muzyka-sfx.md` | Prompt ElevenLabs Music (75 s), firmowy dźwięk alertu ZTT, SFX scena po scenie |
| `06-pipeline-produkcji.md` | Krok po kroku: generacja → VO → audio → montaż → wersje na platformy |

**Start tutaj:** przeczytaj `01` i `02`, potem idź krok po kroku przez `06`.
